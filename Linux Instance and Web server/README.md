# AWS EC2 Linux Instance and Apache Web Server

## 📌 Project Overview

This project demonstrates how to launch an Amazon EC2 Linux instance and configure an Apache Web Server on Amazon Web Services (AWS). The objective is to gain hands-on experience with AWS cloud infrastructure, Linux server management, and web hosting.

## 🚀 Project Objectives

- Launch an Amazon EC2 Linux Instance
- Configure Security Groups for secure access
- Connect to the instance using SSH
- Install and configure Apache HTTP Server
- Host a sample web page
- Understand AWS networking concepts such as VPC and Availability Zones

## 🛠️ Technologies Used

- Amazon Web Services (AWS)
- Amazon EC2
- Amazon Linux
- Apache HTTP Server
- SSH
- VPC
- Security Groups

## 📋 Prerequisites

Before starting, ensure you have:

- An AWS Account
- Basic knowledge of Linux commands
- SSH Client (PuTTY or Terminal)
- Key Pair (.pem file)
